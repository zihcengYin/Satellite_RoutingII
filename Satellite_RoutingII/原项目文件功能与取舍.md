# Satellite_Routing 原项目文件功能与取舍

目标：从原项目整理一套容易理解的 MATLAB 代码，生成 Walker-Star / Walker-Delta 星座的卫星坐标、星间链路长度，以及 2D/3D 示意图。本文依据 `D:\Program Files\MATLAB\project\Satellite_Routing\Satellite_Routing` 下的实际代码；“保留”表示保留功能和规则，通常应整理成新函数，而不是把依赖大量 `global` 的旧脚本直接复制进去。

判断标记：**必需**＝第一版必须实现；**参考**＝可摘取相关片段；**后续**＝做星内最短路或纬度负载实验时再用；**跳过**＝当前目标不需要。

## A. 星座生成、坐标和拓扑：先读这些

| 文件 | 功能（两句话） | 本阶段取舍 |
|---|---|---|
| `Main_PPT.m` | 集中设置地球参数和各星座的 `M/N/高度/倾角/RAAN 范围`，循环调用轨迹函数并保存 `Trajectory*.mat`。其中还混入城市数据、地面覆盖及多次覆盖赋值，需只提取星座配置和轨迹生成流程。 | **必需：提取流程**；参数差异见已有《Walker星座参数与项目规则》。 |
| `fun_SatelliteTrajectory.m` | 根据倾角、RAAN、平近点角等参数计算单颗卫星各时刻的位置，返回 `Orbit_ECI` 和 `Orbit_LLA`。它依赖 `eci2lla`，且均角速度计算中 `mu` 的米单位与轨道半径的千米单位混用，整理时需核查并修正单位。 | **必需：提取并整理**。 |
| `fun_SatelliteNeighbors.m` | 给出卫星 `(m,n)` 的同轨前后和相邻轨道两侧候选邻居，编号到边界时循环。它定义了原项目的“同编号跨轨连接”规则，但 Star 接缝要在建图时处理。 | **必需：保留规则**。 |
| `fun_Graph.m` | 用 `fun_SatelliteNeighbors` 建立纯卫星星间图，轨内/轨间边长由三维坐标欧氏距离取得。对 `orbit_range_deg=180` 跳过末轨道面到首轨道面的跨轨边，并把最终图权重从 km 转为传播时延 ms。 | **必需：提取星内拓扑和 km 链路长度**；新代码应分别保存长度矩阵与时延矩阵。 |
| `fun_Distance.m` | 对两个三维向量计算欧氏距离。原图的 ISL 长度由此函数计算，没有采用地表弧长。 | **必需：保留计算方式**，实现可直接用 `norm(a-b)`。 |
| `Main_PPT_Plot.m` | 包含地球球面、卫星、轨内/轨间 ISL 的 3D 绘图，以及卫星经纬度和链路的 2D 地图绘图。文件还混有地面城市、覆盖和路由区域的绘制，且部分分支引用原目录中不存在的 `fun_CityConnect`，应只摘取星座示意所需片段。 | **必需：参考 2D/3D 画法**，建议重写为独立绘图函数。 |
| `Main_routing_RandomPath.m` | 把星座配置、节点编号、轨迹、地面城市、路由和地图绘制串成一次实验。对于本阶段主要参考其星座参数、`Index2to1/Index1to2` 编号及 2D 卫星图，不需引入随机路由部分。 | **参考**；后续星内路径任务可再读路由段。 |
| `Main_Routing_IntraDomain_InterOrbitISL.m` | 读取轨迹并在多个时间点计算轨内、轨间 ISL 时延，形成“纬度—轨间 ISL 时延”数据。与本阶段的链路长度验证直接相关，但原脚本包含大量重复初始化和画图代码。 | **参考**；可借鉴数据采样，不直接复制。 |
| `Main_Routing_IntraDomain_InterOrbit_F.m` | 重新生成轨迹并计算不同纬度位置的轨间链路时延，画出多条轨间链路曲线。适合用于理解相位 `F` 和纬度对 ISL 的影响；其中一些乘零项是实验残留。 | **参考**；用于检查新实现的曲线趋势。 |

## B. 地面城市与接入：星内目标暂时不用

|---|---|---|

| `fun_LEOforNode.m` | 从可覆盖某地面节点的卫星中选出距离最近者。它是地面接入策略，不用于卫星到卫星最短路。 | **跳过**。 |
| `fun_GraphwithGS.m` | 在星间图上添加源、目的两个地面节点及上行、下行边。其星间拓扑段可对照 `fun_Graph.m`，但新星内实验不应加入这两个地面节点。 | **参考拓扑一致性**；主体跳过。 |

| `fun_Haversine.m` | 计算两个地面城市间的大圆距离。它不是卫星与卫星间的直线 ISL 长度。 | **跳过**。 |
| `fun_FlowPairs.m` | 随机选城市源目的对，并过滤短距离或没有卫星覆盖的城市。后续导师要求的是 satellite-to-satellite 业务对，应另写卫星节点采样器。 | **跳过**。 |

## C. 星内路由及负载：下一阶段再处理

| 文件 | 功能（两句话） | 本阶段取舍 |
|---|---|---|

| `fun_GenRndPathVector.m` | 随机排列规定数量的轨内步和跨轨步，形成最少跳数动作向量。它不计算卫星坐标和链路长度。 | **后续可参考**；非第一版必需。 |
| `fun_GenAlphaPathVector.m` | 根据候选跨轨位置的链路时延，以 `exp(alpha*latency)` 生成抽样概率并插入跨轨动作。它用于路由策略对比，不是 Walker 星座生成规则。 | **后续可参考**；非第一版必需。 |
| `fun_RndDistribution.m` | 按离散概率向量随机抽取位置，供 α 路由使用。没有 α 路由时不需要。 | **跳过**。 |
| `fun_PerformancePathVector.m` | 把 0/1 动作向量转换为卫星节点路径，并用图矩阵累加路径传播时延。后续比较路径时可参考，但应明确新图中权重单位。 | **后续**。 |
| `fun_RoutingPerformance.m` | 用给定的时间变化链路代价矩阵评价动作向量路径。主要服务在线学习实验。 | **跳过**。 |
| `fun_CalculateTraffic.m` | 对一条路径经过的有向边计数，生成链路业务矩阵。后续纬度负载实验可借鉴这个计数概念，但要决定是否合并双向 ISL。 | **后续**。 |
| `fun_PlotTraffic.m` | 将累计链路业务量划分为全部、轨内、轨间等类别，并结合纬度整理统计数据。后续绘制纬度—ISL 负载图时可参考。 | **后续**。 |
| `fun_PlotTrafficGround.m` | 根据城市对起终点纬度生成地面路径跨越的纬度样本。它不用于纯卫星节点对的路径负载统计。 | **跳过**。 |
| `fun_PlotTrafficPlot.m` | 把流量与纬度数据按指定步长分箱。后续可参考分箱思想，但现有实现不必原样保留。 | **后续参考**。 |
| `Main_Routing_IntraDomain.m` | 以两颗指定卫星为起终点，在纯星间图上比较最短时延路径与随机最短跳路径，并绘制二维地图。它是下一阶段星内路径实验最接近的原型。 | **后续重点参考**。 |
| `Main_Routing_IntraDomain_Large.m` | 对较多卫星节点对重复求星内路径，并统计路径涉及的纬度。可参考其批量实验结构；第一版星座图不需要。 | **后续**。 |
| `Main_Routing_IntraDomain_InterOrbit.m` | 改变源目的轨道面的间隔，比较最短路与随机路径的时延变化。属于专门的星内路由实验。 | **后续参考**。 |
| `Main_routing_learning.m` | 在随时间变化的链路代价上运行 EXP3 候选路径学习，并与离线最优结果比较。导师当前目标没有要求在线学习。 | **跳过**。 |

## F. 建议整理出的第一版代码模块

| 新模块 | 功能 | 对应原项目依据 |
|---|---|---|
| `get_constellation_config.m` | 统一返回模型参数，显式记录 Star/Delta、`M/N/H/i/W/F`。 | `Main_routing_RandomPath.m` 为首版参数基准；冲突另存配置。 |
| `generate_constellation.m` | 用配置生成每颗卫星在指定时刻的坐标和经纬度，并输出二维/一维编号映射。 | `Main_PPT.m`、`fun_SatelliteTrajectory.m`、`Main_routing_RandomPath.m`。 |
| `build_isl_links.m` | 按相同 `n` 配对和 Star 接缝规则生成无向轨内/轨间边表；保存 `length_km` 和链路中点纬度。 | `fun_SatelliteNeighbors.m`、`fun_Graph.m`、`fun_Distance.m`。 |
| `plot_constellation_2d.m` | 在经纬度地图上绘制卫星和两类 ISL，处理 ±180° 经线跨越。 | `Main_PPT_Plot.m`、`Main_routing_RandomPath.m`。 |
| `plot_constellation_3d.m` | 绘制地球球面、轨道面卫星及星间连接。 | `Main_PPT_Plot.m`。 |
| `demo_constellation.m` | 选择模型、运行前述模块，输出节点/链路表和 2D/3D 图。 | `Main_PPT.m` 的主流程。 |

完成第一版的检查项：卫星数等于 `M*N`；Delta 的轨间边首尾闭合、Star 接缝断开；所有轨内 ISL 在理想圆轨道中等长；轨间 ISL 长度由实际坐标计算且可按纬度绘图；图中的坐标、链路表和参数表使用同一配置。
